# Observability report

`app/observability/telemetry.py` provides a recording adapter and manual Langfuse adapter. Stage spans report bounded allowlisted metadata and measured elapsed milliseconds. Langfuse scores include claim-validation pass/fail, answer outcome, source-evidence presence, stage latency, model token usage, request count, and agent tool calls, associated with the request trace. These are deterministic grounding and performance measures; they do not claim factual accuracy without a reviewed labeled evaluation set. Principal/customer references are HMAC pseudonyms using a random per-process salt. Query text, raw records, bearer/API credentials, prompts and model outputs have no permitted telemetry fields. Langfuse receives opaque hashed trace IDs; caller-supplied correlation IDs are not included in exported metadata.

The API records request receipt, authentication/authorization and final status. The assistant records routing, retrieval, context, tools, generation and validation as available in its actual execution path. A request context variable joins assistant events to the API correlation identifier. Missing stages are not fabricated for refusal or early failures. Token usage is reported when supplied by the provider; unknown provider prices/costs are marked unknown, rather than inferred from an obsolete price table.

`tests/test_observability.py` verifies redaction, pseudonymous references and graceful degradation on an adapter exception. API tests exercise provider failures, timeout and controlled status responses. Recording-adapter tests do not establish Langfuse server receipt. Export requires both explicit keys; an absent key pair disables export and is visible in health. Langfuse export errors set degraded telemetry and do not fail otherwise valid customer requests.

Live Langfuse trace receipt, screenshots, remote scoring and cost attribution remain **unverified-live** without credentials. The manual SDK API was checked against installed Langfuse 5.0.3 signatures and the [official reference](https://python.reference.langfuse.com/langfuse). Review traces in the configured project and retention policy before deployment with customer data. No raw tracing integration is enabled automatically.
