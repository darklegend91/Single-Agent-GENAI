# Single-Agent GenAI Knowledge Assistant
Project-Based Learning (PBL) Documentation\
Technology stack: Python, FastAPI, LangChain, Milvus, Pydantic AI, Langfuse\
Project type: Individual, end-to-end implementation\
Suggested duration: 5 days\
Primary objective: Build a secure, observable, context-aware RAG application using a customer and subscription dataset.\
Dataset: Link

## Project objectives
By completing this project, learners should be able to:\
Design effective prompts using prompt engineering principles.\
Build context-aware LLM applications using context engineering.\
Implement RAG using embeddings, vector search, and Milvus.\
Generate structured, schema-compliant responses using Pydantic.\
Integrate Pydantic AI into a single-agent workflow.\
Detect and mitigate hallucinations and prompt injection.\
Implement input guardrails, content safety checks, and output validation.\
Expose the application through FastAPI endpoints.\
Instrument the application using Langfuse for tracing, debugging, and evaluation.\
Evaluate answer quality, retrieval relevance, latency, and cost.
